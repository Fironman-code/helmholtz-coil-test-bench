# Helmholtz Coil Test Bench

Python project for processing, analysing and validating measurement data from a Helmholtz coil experimental setup.

## Project goals

- Import experimental data from CSV files
- Clean and validate measurement data
- Calculate basic magnetic-field quantities
- Visualise measured data
- Compare measured and theoretical results
- Create automated tests for analysis functions

## Project structure

- `data/raw/` - original measurement data
- `data/processed/` - cleaned and generated data
- `notebooks/` - exploratory data analysis
- `src/helmholtz_test_bench/` - Python source code
- `tests/` - automated tests
- `docs/` - technical documentation
